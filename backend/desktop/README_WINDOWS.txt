정보화 설계 도우미 — Windows 시험판(미서명)

1. 이 ZIP을 바탕화면 등 원하는 곳에 "모두 압축 풀기" 합니다. (ZIP 안에서 바로 실행하지 마세요)
2. CJ-SW-Design 폴더의 CJ-SW-Design.exe 를 더블클릭합니다.
   - 서명하지 않은 시험판이라 Windows가 경고할 수 있습니다. 기관 보안 정책에 따라 판단하세요.
3. 처음 실행이면 로그인 비밀번호(10자 이상)를 정합니다.
4. 잠시 뒤 기본 브라우저가 열리면 그 비밀번호로 로그인합니다.
5. 끝낼 때는 런처 창의 [종료]를 누릅니다. 브라우저 탭만 닫으면 프로그램은 계속 실행됩니다.

- 데이터 위치: %LOCALAPPDATA%\CJ-SW-Design (프로그램 폴더를 지우거나 새 버전으로 바꿔도 남습니다)
- AI 키가 없으면 샘플 모드(규칙 기반, 외부 전송 없음)로 동작합니다.
  [설정]에서 OpenAI API 키를 넣으면 AI를 쓸 수 있으며, 이때 업무 내용이 OpenAI로 전송되고 사용료가 청구됩니다.
- 자세한 안내: 저장소 docs/WINDOWS.md
