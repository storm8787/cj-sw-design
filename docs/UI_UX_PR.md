# 정보화 설계 도우미의 시작·단계 이동·비교표 UX 개선

처음 사용하는 공무원이 긴 설명을 읽기 전에 시작 방법과 현재 행동을 찾을 수 있도록 일반 앱과 Pages 시연판의 공통 UI를 개선합니다. 일반 홈은 구상·참고문서·기존 문서 검토와 별도 이어하기를 제공하고, 시연 홈은 샘플 A/B 보기·다운로드를 중심으로 구성합니다.

공통 토큰·헤더·접근 가능한 dialog(모바일 하단 시트)·실제 로딩 스켈레톤을 추가했습니다. 단계별 제목·이전/다음 이동·핵심 다음 입력 및 전체 목록, 개요 상세 설정, 비교표 상태 필터·ID 상세 근거, 저장 피드백과 개요 미저장 경고를 제공합니다. ID 관계, FP·금액 산식과 기준, 엑셀 생성, 인증과 전송 동의, 빌드 시 demo 모듈 분리·읽기 전용 보호는 유지합니다.

검증: 타입 검사·일반/시연 빌드·샘플 생성/검증, 백엔드 120개, 일반 앱 구상/문서 E2E, 시연 E2E 및 추가 UX E2E 통과. A/B 7단계를 1400/820/390px에서 검증하고 필터·시트·Tab/Esc/포커스 복귀·로딩·오류 재시도·저장/재접속을 확인했습니다. 시연 API/외부 요청·콘솔 오류·404는 0건입니다.

변경 전후 로컬 스크린샷은 `/workspace/artifacts/cj-design/`에 있습니다. DESIGN_SYSTEM·AGENTS 및 공통 지침·인수인계·검증 문서를 갱신했습니다. 원격 기존 브랜치의 미병합 af4fbdc(Pages 배포 기록) 문서도 보존했습니다.

공개 참고 홈페이지/Pages는 환경 프록시에서 차단되어 직접 확인하지 못했습니다. 공식 토스 Frontend Fundamentals 자료는 확인했습니다. 실 모바일 기기·스크린리더와 공개 배포 후 검증은 남아 있습니다. Render 배포·main 병합·유료 AI 호출은 하지 않았습니다.
