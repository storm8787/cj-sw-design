# 평가자 체험 순서

처음 보는 분이 15~30분 안에 이 도구의 가치를 확인할 수 있도록 정리했습니다. 모두 가상 자료입니다.
**가치가 드러나는 흐름:** 업무 질문 → 요구사항(사용자 기능 보존) → 설계 → FP 근거(업무 확인, 코드 집계) → 기준 산정 → 별도 목표예산 → 엑셀에서 ID로 추적.

## 0. 접속과 확인
1. https://sw-design-helper.onrender.com 접속 → **관리자 비밀번호**로 로그인(접속 정보는 별도 전달).
2. 화면 오른쪽 위 AI 표시를 봅니다.
   - 'OpenAI(ChatGPT) · gpt-6-luna (작업별: FP 후보 gpt-6.1-sol)': 권장 AI 구성이 적용된 상태입니다.
   - '샘플 모드(규칙 기반, AI 아님)': AI 키 없이 서버 규칙으로 만드는 상태입니다.
3. 첫 화면 **예제로 체험하기**를 펼칩니다.

빠른 결과 열람과 직접 AI 실행의 차이:
- '완성 예시 열기'와 읽기 전용 시연판은 **미리 만든 결과**입니다. 몇 초면 열리고 AI를 부르지 않습니다.
- 직접 '질문 받기'·'초안 만들기'를 누르면 AI 연결 시 외부 AI를 호출합니다. 전송 범위 확인 창에서 동의해야 진행됩니다.
- 참고 소요 시간은 2026-10-30 로컬에서 gpt-6-luna(+FP 후보 gpt-6.1-sol)로 잰 값입니다. 운영 서버·시점에 따라 다릅니다.
  - 질문·요구사항: 약 20~40초(1회 97초 기록)
  - 설계 초안: 약 40~65초
  - FP 후보: 약 30~80초
  - 문서 추출: 약 5~10초
  - 샘플 모드는 몇 초 안에 끝납니다.

## 흐름 1 — 구상에서 엑셀까지 (예제 A)
| 할 일 | 기대 화면·결과 | 확인할 점 |
|---|---|---|
| 예제로 체험하기 → **예제 값으로 시작** → **만들기** | 사업명·구상·목표예산 8천만 원이 채워진 창, 만든 뒤 '2 자료·질문' | 누르기만으로 프로젝트·AI 호출이 생기지 않고 '만들기'에서 생성 |
| **질문 받기** → 답하거나 '모름' | 질문 몇 개씩, '왜 묻나요?'와 권장 선택지 | 전문용어(DET·EI) 없이 업무 말, '모름'은 가정으로 기록 |
| '3 요구사항'에 [입력 예시](../examples/A-idea/idea_example.md)의 일곱 줄 → **요구사항 초안 만들기** → 적용 | 변경안 비교표 | 직접 쓴 일곱 기능이 '사용자' 출처로 모두 남고, 추가 제안은 따로 표시 |
| '4 설계' **요구사항으로 설계 초안 만들기** → 적용 | 기능·화면·데이터·연계 표, 요구사항 ID 연결 | 확인되지 않은 연계는 '미확인'으로 남음 |
| '5 FP·개발비' **기능·데이터로 FP 후보 만들기** → 적용 → **업무 확인** 표에서 있음/없음/모름 | 'FP 집계'의 간이법이 '미산정' → '추정 산정 N FP' | 숫자 입력이 없고, 0건일 때 0원 견적이 나오지 않음 |
| **기준 산정 실행·저장** → **시나리오 만들기**(목표 8천만 원) | 견적 버전과 '예산 조정 결과(참고, 공식 측정값 아님)' | 기준 FP·기능은 그대로, 조정률·환산값만 따로 |
| '7 엑셀' **엑셀 내려받기** | 사업개요(산정 요약)·개발비_기준·FP 시트·검산 | 검산 시트 '일치', 요구사항 ID가 FP·근거 시트까지 연결 |

## 상태 표시의 뜻
- **미산정 / 부분 / 추정 / 확정 산정**
  - 미산정: 집계 0건.
  - 부분: 아직 판단하지 않은 후보·미분류·중복 의심·FP 미연결 요구사항이 남음.
  - 추정: 업무 확인만 한 항목이나 가정이 포함됨.
  - 확정: 모든 집계 항목이 기술 검토 확정.
- **미실행**: 검토·산정을 아직 하지 않은 상태입니다. '문제 없음'이 아닙니다.
- **가정**: 질문에 '모름'으로 답해 권장안을 가정으로 채택한 것입니다. 사실로 확인된 것이 아닙니다.
- **검산 일치**: 엑셀 수식과 Python 계산값이 같다는 뜻입니다. 설계가 타당하다는 보증은 아닙니다.
- **갱신 필요**: 견적을 만든 뒤 FP·설정이 바뀌었다는 뜻입니다. 과거 견적은 보존됩니다.

## 접속이 안 되거나 AI가 안 될 때
| 상황 | 대안 | 대안으로 확인할 수 있는 범위 |
|---|---|---|
| 실제 앱 접속 불가 | 읽기 전용 시연판 https://storm8787.github.io/cj-sw-design/ | 미리 만든 샘플 2종의 전 단계 화면·엑셀, 예제 파일 받기. 업로드·AI·저장은 없음 |
| AI 키 없음·AI 실패 | 같은 앱에서 샘플 모드, 또는 내 PC 실행(README) | 규칙 기반 초안으로 전체 흐름·계산·엑셀·검토 |
| 내 PC 실행 | [구동안내서 2절](RUN_GUIDE.md#2-설치실행-절차) | 실제 앱과 같은 기능 |

**대안은 실제 AI 구동을 대신 입증하지 않습니다.** AI 결과 확인은 AI가 연결된 앱에서만 가능합니다. AI 문장·ID·FP 수치는 실행마다 달라질 수 있습니다.
