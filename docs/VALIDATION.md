  - 정통법: 근거 목록 집계 — 환급 정보 DET 8·RET 2 → L 7, 가맹업소 DET 5·RET 1 → L 7, 신청 EI DET 6·FTR 1 → L 3. 나머지는 '근거 부족'으로 부분 산정, 간이법 경고에는 섞이지 않음.
  - 재실행해도 FP 개수 그대로. 설정 저장만으로 견적 없음. 엑셀: 간이법 '추정 산정', 정통법 '부분 산정', 근거 시트 확인 목록(외부·기관 확인, 미실행).
- **B. 가상 체육시설 대관**(구상 기반): 이름 중복 없음, 업무 확인 후 간이법 = 유형별 가중치 합(독립 계산), 다른 언어 이름 → 확인 목록 'FP 기술 검토 필요'.
- **C. AI 재실행(모의 공급자)**: 같은 처리 → 갱신 변경안(빈 칸만, 기존 근거 유지), 비슷한 처리 → '비슷함' 표시 추가, 대기 중 변경안과도 중복 안 함, AI가 준 DET 숫자 미저장.
- 기존 데이터 호환: 새 필드 없는 저장 데이터가 기본값으로 읽힘.
