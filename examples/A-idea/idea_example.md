# 예제 A — 구상으로 시작하기 (가상 사업)

화면: 첫 화면 **구상으로 시작하기** → 아래 값 입력 → **만들기**
(첫 화면의 '예제로 체험하기 → 예제 값으로 시작'을 누르면 1~4가 미리 채워집니다.)

1. 사업(프로젝트) 이름: `[예제] 직원 교육 신청·관리 시스템 구축`
2. 사업 유형: 일반 SW·정보시스템 신규개발
3. 금액 조건: 개발비 지정(목표예산 시나리오도 작성) / 목표 금액 `80,000,000` / 목표 금액에 부가세 포함
4. 처음 구상: `직원 교육 신청·관리 프로그램이 필요하다. 신청·취소·승인과 정원 초과 시 대기자 관리, 이수 통계가 필요하다.`

**3 요구사항** 단계의 기능 입력란에 아래 일곱 줄을 붙여 넣고 **요구사항 초안 만들기**를 누릅니다.

```text
교육과정 등록·수정·삭제
교육 신청: 직원이 신청기간 내 신청
신청 취소: 교육 시작 전까지
신청 승인·반려
정원 초과 시 대기자 자동 승계
과정별 신청·이수 통계
신청 내역 조회
```

확인할 점(AI·샘플 규칙 어느 쪽이든 문장·ID·FP 수치는 실행마다 달라질 수 있음):
- 직접 쓴 일곱 기능이 모두 요구사항에 '사용자' 출처로 남는가(추가 제안은 따로 표시)
- 질문이 DET·EI 같은 전문용어 없이 업무 말로 나오는가, '모름'은 가정으로 기록되는가
- **5 FP·개발비**에서 숫자 입력 없이 '업무 확인'(있음/없음/모름)만으로 간이법 '추정 산정'이 되는가
- 기준 산정과 목표예산 시나리오가 따로 표시되고, 기능을 줄이지 않는가
