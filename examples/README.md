# 모의데이터(예제) — 모두 가상 자료

실제 기관·사업·개인정보·연락처·계좌는 들어 있지 않습니다. 화면의 **예제로 체험하기**에서 내려받는 파일과 이 폴더의 파일은 같은 원본입니다
(FP 산정표만 저장소에는 CSV, 화면·시연판에서는 같은 내용의 엑셀로 내려받음). 원본 파일은 읽기 전용으로 두고, 앱에 올린 뒤 생기는 결과는 앱의 프로젝트에 따로 저장됩니다.

| 예제 | 파일 | 투입 화면·순서 | AI 필요 | 확인할 점 |
|---|---|---|---|---|
| A. 구상으로 시작하기 | [A-idea/idea_example.md](A-idea/idea_example.md) | 첫 화면 '예제로 체험하기 → 예제 값으로 시작'(사업명·구상·목표예산이 채워진 만들기 창) → **2 자료·질문** 질문 받기 → **3 요구사항**에 기능 일곱 줄 붙여 넣기 → **4 설계** → **5 FP·개발비** → **7 엑셀** | 아니오(키가 없으면 샘플 규칙, 있으면 AI. 실행 버튼과 전송 동의를 거칠 때만 호출) | 직접 쓴 기능 보존, 업무 말 질문, 숫자 입력 없는 업무 확인 → 추정 산정, 기준 산정과 목표예산 분리 |
| A'. 완성 예시 | (파일 없음) | '예제로 체험하기 → 완성 예시 열기: 교육 신청·관리 / 민원·배치 연계' — 샘플 규칙으로 미리 채운 **새 프로젝트**를 만듭니다 | 아니오 | 처음부터 끝까지 채워진 화면·엑셀 구조 |
| B. 참고문서로 시작하기 | [B-reference/reference_task_order.txt](B-reference/reference_task_order.txt) | **참고문서로 시작하기** → **2 자료·질문**에서 문서 종류 '참고문서(타 기관)'로 올리기 → **항목 추출** → 항목별 유지·수정·제외 → **3 요구사항** | 아니오(AI 연결 시 원문 전송 동의 후 AI 추출) | 원문·줄 위치 보존, 예산·기간·특정 제품(Oracle)·개인정보 줄의 '타 기관 고유 조건' 표시, 문서 속 지시문을 실행하지 않음 |
| C. 기존 문서 검토하기 | [C-review/](C-review/) 4개 파일 + [기대 확인 목록](C-review/expected_findings.md) | **기존 문서 검토하기** → **2 자료·질문**에서 종류별로 올리기 → **6 검토·추천** → **검토 실행** | 아니오(규칙 기반 검토) | 넣어 둔 오류 5종이 '차이 발견'·'확인 필요'로 나오는가, 탐지 못하는 한계 |

- AI 결과(문장·ID·FP 수치)는 실행마다 달라질 수 있습니다. 비교할 것은 요구 기능 보존·출처 연결·미확정 표시처럼 안정적인 항목입니다.
- 정적 시연판(GitHub Pages)에서는 업로드·실행이 되지 않습니다. 파일 내려받기와 미리 만든 샘플 A(완료)·B(확인 필요) 결과 열람만 됩니다. 예제 C의 검토 실행은 실제 앱에서 합니다(샘플 A의 '6 검토·추천'에서 비슷한 검토 결과를 열람할 수 있음).
